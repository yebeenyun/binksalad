# 빙크샐러드

[English](./README.md)

## 실행하기

Node.js와 Python 3가 설치된 환경에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행하세요.

```sh
npm install
python scripts\ensure-python-deps.py
npm run dev
```

브라우저에서 `http://localhost:5173`을 여세요. 첫 실행 시 이 컴퓨터에서 사용할 소유자 비밀번호(12자 이상)를 설정하면 `owner` 계정이 만들어집니다. 초기 설정이 끝난 뒤 로그인 화면의 **회원가입**을 누르면 사용자 이름과 비밀번호로 별도의 개인 가계부를 만들 수 있습니다. 카카오 계정은 필수가 아닙니다.

`npm run dev`는 프론트엔드와 API 서버를 함께 시작합니다. 두 서버를 따로 실행하지 마세요. 개발 서버는 로컬 컴퓨터에서만 열립니다. 모바일/LAN 사용은 아래 `start-internal.bat`을 이용하세요.

## 카카오톡 계정 연결

카카오 로그인을 사용하려면 [Kakao Developers](https://developers.kakao.com/)에서 앱을 만들고 카카오 로그인을 활성화한 뒤, REST API 키의 클라이언트 시크릿을 켜고 리다이렉트 URI를 등록하세요. 등록 URI는 앱을 여는 기기에서 접근 가능해야 하며 `KAKAO_REDIRECT_URI` 값과 정확히 일치해야 합니다.

서버를 실행하기 전에 PowerShell에서 다음 환경 변수를 설정하세요.

```powershell
$env:KAKAO_REST_API_KEY = "카카오 REST API 키"
$env:KAKAO_CLIENT_SECRET = "카카오 클라이언트 시크릿"
$env:KAKAO_REDIRECT_URI = "https://내-고정-도메인/api/auth/kakao/callback"
.\start-internal.bat
```

개발 서버는 같은 PowerShell에서 `npm run dev`로 실행합니다. REST API 키와 클라이언트 시크릿은 브라우저로 전송되거나 저장되지 않습니다. 카카오 계정을 연결한 뒤 로그인 화면의 카카오 로그인 버튼을 사용할 수 있습니다. 임시 Cloudflare URL은 주소가 바뀌므로 고정 리다이렉트 URI로 카카오 로그인을 구성할 수 없습니다.

## 공용 가계부와 카카오뱅크 계좌

**가계 관리**에서 카카오뱅크 계좌 별칭과 선택적 계좌번호 끝 4자리를 등록하고 구성원을 초대할 수 있습니다. 초대 링크는 1회만 사용할 수 있고 7일 후 만료됩니다. 초대받은 사람은 사용자 이름과 비밀번호를 만들어 가입합니다. 소유자는 조회 전용 또는 거래 편집 권한을 부여하고, 대기 중인 초대를 취소하거나 구성원을 제외할 수 있습니다. 조회 전용 구성원은 같은 거래와 대시보드를 볼 수 있지만 거래 추가·수정·삭제 및 엑셀 가져오기는 할 수 없습니다.

엑셀 가져오기에서 거래를 연결할 계좌 별칭을 선택합니다. 중복 거래 판정도 계좌별로 이루어집니다. 앱은 카카오뱅크 로그인 정보나 전체 계좌번호를 요청하거나 저장하지 않습니다.

카카오 로그인은 빙크샐러드 사용자 인증 기능이며 카카오뱅크 계좌 데이터 접근 권한을 주지 않습니다. 현재 공식 카카오뱅크 연동으로 계좌를 자동 조회하는 기능은 구현·검증되지 않았으므로, 사용자가 거래내역 XLSX를 내려받아 직접 가져와야 합니다.

## 같은 Wi-Fi에 연결된 휴대폰에서 사용하기

프로젝트 폴더의 `start-internal.bat`을 더블 클릭하면 필요한 패키지를 확인하고 프론트엔드를 프로덕션 빌드한 뒤 통합 서버를 실행합니다. 서버는 호스트 컴퓨터에서 감지한 사설 IPv4 서브넷 내의 기기만 허용하며, 다른 네트워크의 요청은 거부합니다. 처음에는 이 컴퓨터에서 `http://localhost:4173`을 열어 소유자 비밀번호를 설정하세요. 그 다음 같은 Wi-Fi에 연결된 휴대폰에서 컴퓨터의 사설 IPv4 주소로 접속합니다. IP 주소는 Windows 명령 프롬프트에서 `ipconfig`를 실행해 확인할 수 있습니다.

예를 들어 컴퓨터의 주소가 `192.168.1.25`라면 다음 주소로 접속합니다.

```text
http://192.168.1.25:4173
```

접속되지 않으면 컴퓨터와 휴대폰이 같은 Wi-Fi에 연결되어 있는지 확인하고, 운영체제 방화벽에서 사설 네트워크의 Node.js 연결을 허용하세요. `start-internal.bat`은 `dist` 빌드 파일을 사용하므로 `localhost:5173`이 아니라 `localhost:4173`으로 접속해야 합니다.

## 다른 네트워크에서 접속하기 (임시 HTTPS 주소)

`192.168.x.x` 같은 사설 IP 주소는 같은 로컬 네트워크 안에서만 사용할 수 있습니다. 외부 네트워크에서 빠르게 테스트하려면 Cloudflare Tunnel을 사용할 수 있습니다. Windows에서는 먼저 PowerShell에서 `cloudflared`를 설치하세요.

```powershell
winget install --id Cloudflare.cloudflared
```

먼저 위의 내부 실행으로 소유자 비밀번호를 설정한 다음, 내부 서버를 종료하세요. 설치가 끝나면 프로젝트 폴더의 `start-external.bat`을 더블 클릭하세요. 또는 프로젝트 폴더에서 다음 명령을 실행할 수 있습니다.

```sh
npm run external
```

명령은 앱을 프로덕션 빌드한 뒤 로그인 보호가 적용된 로컬 API 서버와 임시 HTTPS 터널을 실행합니다. 터미널에 표시되는 `https://...trycloudflare.com` 주소를 휴대폰에서 여세요. 실행을 종료하려면 `Ctrl+C`를 누릅니다. 주소는 임시 주소이며, 명령을 종료하면 더 이상 접속할 수 없습니다.

이 방식은 인터넷에서 접근 가능한 공개 URL을 만듭니다. URL을 아는 사람은 누구나 앱을 볼 수 있으므로 공유에 주의하세요. Vite 개발 서버를 인터넷에 직접 공개하지 마세요. 장기적으로 사용하려면 HTTPS를 지원하는 정적 웹 호스팅 서비스에 `dist` 폴더를 배포하거나 안전한 사설 VPN을 사용하세요.

계정 비밀번호는 scrypt로 해시 처리하고, 세션은 HttpOnly 쿠키로 보호합니다. 거래 데이터는 `data`의 SQLite 데이터베이스에, 저장을 선택한 엑셀 비밀번호는 별도 `.secrets` 키를 사용한 AES-256-GCM 암호문으로 저장합니다. `data`와 `.secrets`를 모두 별도로 백업하고, 키 파일을 데이터베이스와 함께 공개 저장소에 올리지 마세요.

최초 계정은 호스트 컴퓨터에서 소유자가 설정합니다. 카카오 계정 연결/로그인은 개발자 키와 고정 리다이렉트 URI를 설정해야 하며, 실제 카카오 콜백 테스트는 앱 자격 증명이 있어야 가능합니다. 공용 가계부 초대와 계좌별 XLSX 거래 가져오기는 구현되어 있습니다. 가계부 전환, 메일·푸시 알림, 연도별 분석은 아직 구현되지 않았습니다. 실제 암호화 카카오뱅크 파일의 비밀번호는 사용자가 입력해야 하며, 제공되지 않은 비밀번호를 자동으로 알아낼 수는 없습니다.

## 프로덕션 서버

프론트엔드를 자동으로 빌드하고 화면과 API를 한 번에 실행하려면:

```sh
npm start
```

서버 기본 주소는 `http://127.0.0.1:4173`입니다. `start-internal.bat`은 프로덕션 빌드를 사용해 `0.0.0.0:4173`에 바인딩하지만, 호스트의 사설 IPv4 서브넷에 속한 기기만 허용하고 그 외의 요청은 거부합니다. 첫 소유자 설정이 완료된 뒤에는 로그인 화면에서 사용자 이름과 비밀번호로 가입할 수 있으며, 가입 시 서로 분리된 개인 가계부가 만들어집니다.
